t02 - first run: the server starts, unclaimed, and answers on loopback
Date: 2026-11-02T15:23:46+00:00

Plex's own web/API port is 32400 - that is the product's genuine
default, so the lab uses it on loopback and the server is shut
down when the lab ends (t08). No other port is used.

Start (all state - database, logs, cache - inside the lab folder):

  PLEX_MEDIA_SERVER_APPLICATION_SUPPORT_DIR=$LABWORK/support \
  PLEX_MEDIA_SERVER_HOME=$LABWORK/root/usr/lib/plexmediaserver \
  TMPDIR=$LABWORK/tmp \
  "$PLEX_MEDIA_SERVER_HOME/Plex Media Server"

One honest warning from that log, seen repeatedly:
Nov 02, 2026 15:21:03.956 [129800972118840] WARN - NetworkServiceBrowser: Error sending out discover packet from 127.0.0.1 to 127.255.255.255: Operation not permitted
Discovery beacons are UDP broadcasts; this sandbox permits no
UDP, so automatic discovery cannot work here. Clients on a real
home network would find the server by that beacon; here we use
the address directly. Nothing else in the lab needs UDP.
