The web app is served in full by the server itself - it is not a
download from plex.tv. In a browser on the local network, opening
it on an unclaimed server starts the setup flow: name the server,
then sign in to a Plex account to CLAIM it (bind it to the
account). That sign-in is interactive and needs a real plex.tv
account, so it cannot be done by this headless lab and is
documented-only in the guide. What the lab can prove is the
state on both sides of that line:

$ curl -s http://127.0.0.1:32400/myplex/account
